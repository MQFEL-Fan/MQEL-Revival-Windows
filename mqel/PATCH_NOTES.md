## 2026-11-21: WASD movement and key binds

**You can now move your hero with W A S D, and change your key binds in
game.**

### What's new
- **WASD movement during attacks.** W moves up the screen, A left, S down,
  D right, and diagonals work. Your mouse keeps working as usual: click a
  monster to attack it and aim abilities with the cursor.
- **Mouse and keyboard work together.** Whatever you pressed last wins.
  Click a monster while walking and you attack it. Hold the attack and press
  WASD and you step aside; let go of WASD and you go back to attacking what's
  under your cursor. Your cursor never jumps.
- **Ctrl+WASD** walks without attacking, **Shift+WASD** holds the ground.
- **KEYS button** in the lobby top bar, left of the gear: change the WASD
  keys, how far each step reaches ("Click distance"), and every game key
  bind (abilities, camera, emotes, building).
- **Keys set up for you:** W, A and D used to rotate the camera. On your
  first start the camera moves to Q/E (and the arrow keys) and Ability 5
  from Q to R. Change anything in the KEYS panel.

### Why it needed a helper file
The game itself has no keyboard movement, and it ignores the gamepad stick
for walking. It only walks where you hold the mouse button. A small helper
file next to the game (`xinput9_1_0.dll`) turns W A S D into "hold the button
next to your hero", without touching your real mouse.

### How to get it
Delivered automatically: start the game from Steam and let the launcher
finish its update. Everything is set up on the first start: WASD on, camera
on Q/E, Ability 5 on R. The KEYS panel opens once by itself to show you.

If you copied `xinput9_1_0.dll` into `GameData\Bin` by hand while testing,
delete it before starting the launcher.

## 2026-11-20: "More castles" no longer freezes the game

**The button that rerolls the castles in a region works reliably again.**

### What was wrong
Clicking **More castles** (with gold or blings) on the attack map could leave the
game on an endless loading screen. The only way out was to close the game.
After restarting, the button often worked, which made the problem look random.

### Why
Every message the server sends to the game carries a running number, so the
game can tell new messages from ones it already handled. The reroll message
also put a second number into the same field: how many times you had rerolled
that region. When that count matched a number the game had already seen (for
example on your first reroll right after a "forge item ready" message), the
game threw the castle list away as old news and kept waiting for it forever.

### What we changed
- The reroll message no longer overwrites the running number, so the game
  always accepts the new castle list.
- As a safeguard, no server message can overwrite that number any more.

### How to get it
Server-side fix, already live: nothing to install. Tested in game with several
gold and bling rerolls in a row. Gold and blings spent on rerolls were always
charged correctly, and the new castles were rolled; only the display got stuck.

## 2026-11-20: Bling counter fix

**The bling counter in the top bar is back.**

### What was wrong
Next to the green gem in the lobby's top bar, the number of blings you own was
empty. Only the gem icon showed. This happened to every player, on every
account.

Your blings were never lost. The server kept your balance the whole time, and
you could still earn and spend blings. Only the number on screen was missing.

### Why
The Steam version of the game shows the bling counter in a different place
than the script that fills it in expects. The script never found the counter,
so it stayed blank.

### What we changed
- The counter is found and filled in again, in the Steam version and in older
  game versions.
- The amount shows with thousands separators (for example **1,230**), right
  away when you earn or spend blings too.

### How to get it
Nothing to download by hand. Start the game from Steam and let the launcher
finish its update; the fix is part of it.

If the counter is still empty, close the launcher completely (including the
tray icon) and start the game again so the update can install.
