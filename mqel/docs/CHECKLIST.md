# Feature-Checkliste

Stand: 2026-10-14. Was der Server kann, was getestet ist und was fehlt.

Quellen für „fehlt“:
- NotificationType-Enumleser des Clients (0x93bxxx)
- `*Command`-Typen im Client gegen die `_cmd_*`-Handler in `server/account_state.py`
- Service-Methoden aus `docs/analysis/api-gameserver.txt`, gefiltert auf Namen, die im finalen Client vorkommen; ohne Admin, Dashboard und SleepyGiant

Legende: `[x]` im Spiel bestätigt · `[~]` gebaut, im Spiel ungetestet · `[ ]` fehlt

## Fertig und im Spiel bestätigt

- [x] Chat (XMPP, `server/xmpp_server.py`): Räume, Nachrichten, Reconnect, Chat für alle Accounts
- [x] Mine ernten: Gold kommt an, aber verzögert (Client sendet Befehle gebündelt)
- [x] Gezielte Angriffe: Verbrauch und 8-h-Nachladen
- [x] Burgvorschau beim Angriff auf Spielerburgen, Par-Zeit-Timer
- [x] Achievements, Tränke, Freunde als AccountSummary, Länder, Test-Angriff (Visit), Burg-Bewertung

## Gebaut, im Spiel ungetestet

- [x] Sterne im Abschlussbildschirm wie `TrophyManager`: Schatzkammer, unter der Validierungszeit, alle Minen zerstört (Wiederbelebung = 0)
- [~] Chat: Presence/away an Raumteilnehmer (braucht zwei Spieler)
- [~] Chat: private Nachrichten, Verhalten ohne laufenden Chat-Server
- [~] LastSeenOnline (zeigt die Oberfläche nirgends an)
- [~] CastleRatingFreePrize None beim Visit
