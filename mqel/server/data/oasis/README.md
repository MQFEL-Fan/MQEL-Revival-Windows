# Game texts (not included)

The server needs the game's original text files `oasis_<lang>.json`
(de, en, es, es-mx, fr, is, it, pl, pt, pt-br, ru) in this folder. They are
Ubisoft's files and are not part of this repository.

Copy them from your own Steam install of the game (client 0.36.1.34.0):
`GameData/Data/Oasis/oasis_*.json` (skip `oasis_customText.json`).
