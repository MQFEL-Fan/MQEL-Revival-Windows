Install

  1. Install via Steam: open steam://install/239220 (you can paste it into your browser).
  2. Download our PublicLauncherSettings.json and use it to replace the existing file in the installation folder (Launcher\). Everything in one zip, with instructions: player-pack.zip.
  3. Choose how you want to play:
    Steam login and achievements

    A: Start from Steam

    Download steam-launcher-patch.cmd, put it into the installation folder and double-click it. Then start the game from Steam.

    The script lets your launcher install our updates when it is started from Steam and keeps a backup (PublicLauncher.exe.bak). If Windows SmartScreen warns you, choose More info → Run anyway. Achievements you already earned unlock on Steam during your first fight. You log in with your Steam account, no password needed.

    Steam reports a virus (0xE1)? Here's the fix.

    Without Steam

    B: Start the launcher directly

    Delete steam_appid.txt from the installation folder, then start Launcher\PublicLauncher.exe.

    No script needed, but you log in with name and password and get no Steam achievements.

  4. Log in and let the launcher finish its update.
    • A (Steam): the launcher recognises your Steam account. New here? Click Play as new Steam player, your account gets the name from your Steam profile. Already played with us? Log in once with your name and password to link your account, after that Steam logs you in automatically.
    • B (without Steam): create an account with name and password. The 2015 launcher can only load its login page over plain HTTP, so please use a password you don't use anywhere else.
Known issue

Steam: "the file contains a virus or potentially unwanted software" (0xE1)

Windows Defender blocks the patched launcher from way A without showing a warning of its own. It is a false positive. Steam then quietly restores the original files, which is why the launcher shows "Maintenance" afterwards.

  1. Open Windows Security → Virus & threat protection → Protection history.
  2. Open the entry for PublicLauncher.exe and choose Allow on device.
  3. Replace PublicLauncherSettings.json again (step 2) and run steam-launcher-patch.cmd again.

Way B needs no patch and is not affected.

Recommended

Crashes or stutter on a modern PC? Use DXVK

The game uses DirectX 9, which modern graphics drivers handle poorly. DXVK translates it to Vulkan, and players report that the game runs stable with it.

  1. Download the latest dxvk-….tar.gz from the DXVK releases page and extract it (Windows 11 opens it directly, otherwise use 7-Zip).
  2. Copy x32\d3d9.dll from it into GameData\Bin\ in the installation folder, next to MightyQuest.exe. Only this one file, and from x32, not x64: the game is 32-bit.
  3. Start the game as usual.

Needs a graphics card with Vulkan support. If the game won't start on an older card, try DXVK 1.10.3. To undo, delete d3d9.dll again.

To find the installation folder, right-click the game in Steam and choose Manage → Browse local files.

Bling shop shows "Not secure" or a certificate error? Optional: download mqel-server-cert.pem and install-shop-certificate.bat into the same folder and double-click the .bat. It trusts our server certificate for your Windows user only. The game itself works without it.

Ultrawide monitor (21:9)? The game is made for 16:9: in fullscreen at a resolution like 3440×1440, clicks land next to the buttons. Use a 16:9 resolution (e.g. 2560×1440) or windowed mode instead.
