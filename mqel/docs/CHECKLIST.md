# Feature Checklist

Status: 2026-10-14 (feature list), Windows note 2026-11-20. What the server
can do, what is tested and what is missing.

Windows (2026-11-20): server, launcher login, patcher (exe, UI patches,
checksums), HTTPS game connection, account load and startup castle purchase
confirmed on Windows 11 (`05-windows-setup.md`). The feature entries below were
verified on the original (Linux) setup and run on the same server code.

Sources for "missing":
- the client's NotificationType enum reader (0x93bxxx)
- `*Command` types in the client vs. the `_cmd_*` handlers in `server/account_state.py`
- service methods from `docs/analysis/api-gameserver.txt`, filtered to names that occur in the final client; without Admin, Dashboard and SleepyGiant

Legend: `[x]` confirmed in game · `[~]` built, untested in game · `[ ]` missing · `[-]` won't fix

## Done and confirmed in game

- [x] Chat (XMPP, `server/xmpp_server.py`): rooms, messages, reconnect, chat for all accounts
- [x] Harvesting mines: gold arrives, but delayed (the client sends commands in batches)
- [x] Targeted attacks: consumption and 8-hour recharge
- [x] Castle preview when attacking player castles, par time timer
- [x] Achievements, potions, friends as AccountSummary, countries, test attack (Visit), castle rating

## Built, untested in game

- [x] Stars on the result screen like `TrophyManager`: treasure room, under the validation time, all mines destroyed (resurrection = 0)
- [~] Chat: presence/away to room participants (needs two players)
- [~] Chat: private messages, behavior without a running chat server
- [~] LastSeenOnline (not shown anywhere in the UI)
- [~] CastleRatingFreePrize None on Visit
